# Chawla Labs

Landing site for Chawla Labs — apps and open-source initiatives.

## Preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173

## Structure

- `index.html` — page markup
- `styles.css` — layout and visual system
- `main.js` — scroll reveal, header, contact form
- `assets/hero.png` — full-bleed hero photography
